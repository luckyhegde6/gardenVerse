# TDD Command

Run test-driven development workflow for GardenVerse.

## Usage

```bash
/tdd [description]
```

## Workflow

1. **Analyze** — Understand the requirement and identify interfaces
2. **Write failing test** — Create test with expected behavior
3. **Implement minimal code** — Write just enough to pass
4. **Refactor** — Improve code while keeping tests green
5. **Verify** — Run full test suite to confirm

## Test Commands

```bash
# Run all backend tests
npm run test

# Typecheck
npm run typecheck
